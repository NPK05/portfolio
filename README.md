## 🚀 How to Host on GitHub Pages

Follow these steps exactly — no coding required.

### Step 1 — Create the Repository

1. Go to [github.com](https://github.com) and log in
2. Click the **+** icon (top right) → **New repository**
3. Set the repository name to exactly:
   ```
   npk05.github.io
   ```
   > ⚠️ This must match your GitHub username. Since your username is `NPK05`, the repo name must be `npk05.github.io` (all lowercase)
4. Set visibility to **Public**
5. Leave everything else unchecked
6. Click **Create repository**

---

### Step 2 — Upload Your Files

**Option A — Via GitHub website (easiest)**

1. Open your new repository
2. Click **Add file** → **Upload files**
3. Drag and drop your `index.html` file
4. Scroll down, write a commit message like `Add portfolio`
5. Click **Commit changes**

**Option B — Via Git (if you have Git installed)**

```bash
git clone https://github.com/npk05/npk05.github.io
cd npk05.github.io
# Copy your index.html into this folder
git add index.html
git commit -m "Add portfolio"
git push origin main
```

---

### Step 3 — Enable GitHub Pages

1. In your repository, click **Settings** (top menu)
2. Scroll down to **Pages** in the left sidebar
3. Under **Source**, select:
   - Branch: `main`
   - Folder: `/ (root)`
4. Click **Save**

---

### Step 4 — Your Site is Live!

After 1–2 minutes, your portfolio will be live at:

```
https://npk05.github.io/
```

> GitHub may take up to 5 minutes the first time. Refresh the Settings → Pages screen to see the green "Your site is published" confirmation.

## 🔄 How to Update the Portfolio

Whenever you make changes:

1. Go to your repository on GitHub
2. Click on `index.html`
3. Click the **pencil icon** (Edit) or use **Upload files** to replace it
4. Commit the changes
5. The live site updates automatically within 1–2 minutes
